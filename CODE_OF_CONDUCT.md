# Code of Conduct

## Our pledge
Everyone participating in this project — issues, pull requests, discussions —
is expected to behave respectfully and professionally.

## Expected behavior
- Be kind and constructive in feedback
- Assume good intent; disagree with ideas, not people
- Keep discussions on-topic and welcoming for all skill levels

## Unacceptable behavior
- Harassment, hate speech, or personal attacks
- Publishing others' private information
- Spam or disruptive behavior

## Enforcement
Maintainers may remove comments, closes issues, or ban contributors who violate
this code of conduct. Reports can be made privately via GitHub.

This project follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/).
